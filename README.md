## About the Project

NexTalk is a simple collaborative web platform designed for real-time interaction through login, signup, and team-based pages. It demonstrates frontend development skills using HTML, CSS, and JavaScript.

## Features

- User Login Page  
- User Signup Page  
- Team Information Page  
- Responsive UI Design  
- Clean Navigation Flow
